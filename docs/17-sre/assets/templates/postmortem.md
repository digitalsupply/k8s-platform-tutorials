# Postmortem：<一句话标题>

> Blameless：只讨论系统、流程、工具，不评价个人。
> 初稿在事故恢复后 24h 内完成，48h 内评审；行动项必须有 owner 和截止日。

## 1. 元数据

| 项 | 值 |
|---|---|
| 事故编号 | INC-YYYYMMDD-XX |
| SEV | SEV1 / SEV2 / SEV3 |
| 开始时间 | 2026-01-01 10:00 (+08) |
| 检测时间 | 2026-01-01 10:05 |
| 恢复时间 | 2026-01-01 10:35 |
| 影响时长 | 35 分钟 |
| IC / Scribe / Comms | @name / @name / @name |
| 关联变更 | Git commit / ArgoCD sync / Helm release |

## 2. 影响面（量化）

| 维度 | 数值 |
|---|---|
| 受影响用户 | 约 N 人 / N% |
| 失败请求 | N 次 / N% |
| SLO 预算消耗 | N%（窗口：30d） |
| 数据丢失 | 有/无，范围 |
| 收入/合同影响 | 有/无 |
| 受影响服务 | svc-a、svc-b |

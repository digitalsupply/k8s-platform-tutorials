# 状态页 / 对外沟通模板

## 初始通告（T+0）

```text
[Investigating] <服务名> 部分用户可能无法 <功能>。
我们已收到告警，正在排查。影响范围/开始时间：<...>。
下次更新：<15/30 分钟后>。
```

## 进展更新（每 15–30 分钟）

```text
[Monitoring] <服务名> 错误率已从 <N%> 降到 <M%>。
已执行：<回滚/扩容/切流>。
当前影响：<...>。
下次更新：<时间>。
```

## 恢复通告

```text
[Resolved] <服务名> 已于 <时间> 恢复。
影响时长：<N 分钟>；影响范围：<...>。
根因：<一句话>；后续动作：<postmortem/修复>。
```

## 状态页字段

| 字段 | 示例 |
|---|---|
| 组件 | Compassio API |
| 状态 | Degraded / Partial Outage / Major Outage / Resolved |
| 开始时间 | 2026-11-11 10:00 +08 |
| 影响 | 约 30% 用户无法提交作业 |
| 当前动作 | 回滚到上一版本 |
| 下次更新 | 10:30 +08 |

## 原则

- 不猜根因，只说我已知/正在做/下次更新时间；
- 不写内部 IP、Token、个人姓名；
- 对外沟通由 Comms 统一发，工程师不各自在群里发不同版本；
- 恢复后 24h 内给最终说明，不让状态页停在“Investigating”。
